🐍 Python API Library Usage

The parser is structured as a standalone Python library. You can import and invoke it in any Python application, script, Flask/FastAPI service, or serverless function.

1. Basic File Path Parsing

from contract_note_parser import parse_contract_note

# Automatically detects broker (Zerodha, Shoonya, Systematix, etc.) and parses
result = parse_contract_note("path/to/contract_note.pdf", template="auto")

print("Broker Name:", result["broker_details"]["name"])
print("Broker Address:", result["broker_details"]["address"])
print("Client Name:", result["client_details"]["name"])
print("Client Address:", result["client_details"]["address"]) # null if absent, never broker address!
print("Transactions:", result["transactions"])

2. In-Memory Parsing from Raw Bytes (Zero-Disk I/O)

Perfect for cloud functions (AWS Lambda, Google Cloud Run) and web upload handlers where you avoid saving files to disk:

import io
from contract_note_parser import parse_contract_note

# Accepts raw bytes or io.BytesIO stream:
with open("contract_note.pdf", "rb") as f:
    pdf_bytes = f.read()

# Parse directly in memory:
result = parse_contract_note(pdf_bytes, file_name="uploaded.pdf", template="zerodha")

3. Broker Auto-Detection & Supported Templates

from contract_note_parser import detect_broker_template, list_supported_templates

# Detect template and confidence:
template_id, confidence = detect_broker_template("contract_note.pdf")
print(f"Detected {template_id} with {confidence * 100:.1f}% confidence")

# List all templates:
templates = list_supported_templates()
for t in templates:
    print(t["id"], "-", t["name"])

🌐 REST API Endpoints

The built-in web server at http://localhost:5000 provides RESTful HTTP endpoints for integrating with non-Python services (Node.js, Go, Java, C#, PHP).

1. Parse Contract Note

POST /api/parse

Accepts a Base64-encoded PDF payload and returns the structured JSON output.

Field Type Description
file_base64 string (required) Base64 encoded string of the PDF content
file_name string (optional) Filename identifier (defaults to "contract_note.pdf")
password string (optional) PDF password if encrypted (e.g. PAN or DOB)
template string (optional) "auto", "zerodha", "shoonya", "systematix", or "generic"

cURL Example

curl -X POST http://localhost:5000/api/parse \
  -H "Content-Type: application/json" \
  -d '{
    "file_base64": "<BASE64_STRING>",
    "file_name": "zerodha_note.pdf",
    "template": "auto"
  }'

2. List Templates

GET /api/templates

Returns an array of all registered broker templates and metadata.

curl -X GET http://localhost:5000/api/templates

🛡️ Broker Anti-Confusion Guarantees

The template system prevents the classic regex bugs where broker registered addresses or PAN numbers overwrite client details:

  • Strict Coordinate / Section Boundaries: Broker address is isolated to header lines/boxes. Client address is extracted only from dedicated client/party tables or "To," sections.
  • Missing Address Safety: If a digital contract note does not contain a client address, client_details.address is returned as null. It will never take the broker's registered office address.
  • Token Cross-Validation: If an extracted client address shares similarity with the broker's registered office, it is discarded.
  • PAN Segregation: Prevents the broker's company PAN from being misattributed to the client when the client PAN is omitted.
